# MegaDL — PROJECT MAP

## [TECH_STACK]

| Layer | Technology |
|---|---|
| Frontend | Vanilla HTML5, CSS3, JavaScript (ES2022+), PWA |
| CSS Engine | Material You, AMOLED Dark, Glassmorphism, CSS Custom Properties |
| Python Backend | Flask 3.x, flask-cors, SQLite3, threading, subprocess |

### User Journey (GUI Flow)

1. **Open app** → Splash → Backend Detection → Home page
2. **Paste URL** → Fetch Info (extracts metadata via yt-dlp) → Shows thumbnail/duration/formats
3. **Select quality** → Live command preview updates → Click Download
4. **Job queued** → Auto-navigates to Active Jobs → Live progress (speed, ETA, %)
5. **Download completes** → Toast notification → Available in Files/History
6. **Batch mode** → Multi-URL paste → Parse → Queue all → Parallel execution

### Backend Architecture: Modes

**MODE 1 — Python/Flask (Primary)**
```
Flask → DownloadQueue → YtdlpService → subprocess yt-dlp → FFmpeg
                ↓
          SQLite3 (jobs, history, archive, favorites, logs, settings)
```

**MODE 2 — PHP (Fallback)**
```
Apache/index.php → shell_exec/proc_open yt-dlp → FFmpeg
         ↓
   SQLite3 (same schema)
```

### State Machine: Job States

```
queued → fetching → running → done
                          ↘ paused → queued
                          ↘ error → queued (retry) or error (terminal)
                          ↘ cancelled (terminal)
```
